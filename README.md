# 飞书 Agent 接入与验收 Skill

一个面向 Agent 的中文操作流程：连接飞书自建应用，完成用户授权，用最小业务调用验证接入，并生成脱敏验收报告。

作者：[ScarletXt](https://github.com/ScarletXt)  
许可证：MIT。独立社区作品，非飞书或 OpenAI 官方产品。

## 解决的问题

- 应用已发布，但 Agent 仍然无法操作。
- 混淆用户身份、机器人身份、应用可用范围与文件共享权限。
- 多组织配置串号，或不小心覆盖已有连接。
- 为了测试而过度申请权限、暴露凭证或修改生产资料。
- 把某个接口成功误认为所有功能都已开通。

## 使用

将本目录完整安装到你的 Agent 支持的 Skill 目录，保留 `SKILL.md` 和 `references/` 的相对位置。具体安装目录以使用中的 Agent 产品说明为准。

也可以把本目录交给支持技能安装的 Agent，并说：

> 安装这个 Skill。接入我指定的飞书自建应用，使用独立 profile，先做日历和文档的只读验收。不要输出凭证，不发送消息，不修改现有资料。报告已通过与尚未测试的部分。

前提：具备目标应用的配置权限、所需组织审批和业务资源授权；执行环境可运行受支持的 `lark-cli`。本仓库不包含 CLI、机器人服务端、模型 API 或任何真实账号配置。

## 验证范围

本项目是操作型 Skill，不是自动部署程序。发布前检查结构、引用、脱敏与流程一致性；不同 CLI 版本、组织策略和资源类型仍需现场验收。示例不能代替本机 `--help` 与当前官方 API 文档。
