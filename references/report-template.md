# 脱敏报告模板

## 接入结果

- 目标：指定应用与独立 profile（公开版不填真实标识）
- CLI 版本：VERSION_PLACEHOLDER
- 已验证身份：用户 / 机器人 / 尚未通过
- 已通过：仅列实际执行且成功的项目
- 未测试：列出尚未运行的模块和写入操作
- 阻塞项：用错误类别说明，不粘贴敏感原始响应
- 下一步：一个最少必要动作

## 管理员申请说明示例

> 申请用于日常资料检索整理、表格维护、日程管理及会议记录归纳的相关权限，以减少重复操作、提高处理效率。应用按批准的可用范围提供服务，并遵循 API、数据范围及资源授权限制。请协助审核，谢谢。

按实际用途补充群聊、任务等能力，不虚构已实施的安全措施，不隐瞒真实需要的数据范围。

## 验收状态示例（合成）

> 用户身份验证通过；日历查询成功；文档搜索成功但正文读取尚未测试。多维表格、会议资料及所有写入操作未测试。下一步：使用指定测试文档验证正文读取。
